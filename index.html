Install & Run in 60 Seconds

Zero complex setup. Fully native Windows 10/11 compatibility with Python 3.10+.

Windows PowerShell — Executive Setup
# 1. Clone or download the repository
git clone https://github.com/your-username/piano-deck-dashboard.git
# 2. Navigate to project root
cd "piano-deck-dashboard"
# 3. Install required packages (PyQt6, Pillow, pywin32)
pip install -r requirements.txt
# 4. Launch the Executive Dashboard (or double-click run_piano_deck.bat)
python main.py
